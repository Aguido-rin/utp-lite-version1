
# UTP+ Lite

Versión ligera de UTP+, diseñada para funcionar sin conexión estable ni hardware avanzado.

## Características:
- Inicio de sesión con Firebase Authentication
- Horarios y tareas guardados localmente
- Sincronización automática cuando hay internet
- Compatible con dispositivos antiguos
- Versión móvil rápida y responsiva

## Instalación

1. Instala Node.js
2. Ejecuta `npm install`
3. Configura Firebase en `src/firebase.js`
4. Ejecuta `npm start`
